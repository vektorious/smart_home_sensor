Smart Home Sensor — Web Flasher

Install the firmware onto your board straight from the browser — no Arduino IDE, no drivers.

Your browser doesn’t support Web Serial. Use Chrome, Edge, or Opera on a desktop computer. Web Serial needs a secure (HTTPS) connection. Open this page over https://.
⚠️ If the board doesn’t show up, start it in flashing mode.
  1. Unplug the board.
  2. Hold the BOOT button down.
  3. Plug in the USB-C cable while still holding BOOT.
  4. Release BOOT after about 2 seconds.
Use a USB-C data cable — a charge-only cable will never enumerate.

How to flash

  1. Pick a firmware above.
  2. Click Connect and choose the USB JTAG/serial debug unit port.
  3. Choose Install and wait for it to finish.
  4. The board reboots and opens a Wi-Fi access point named <device>-Setup. Join it, and the setup page opens at 192.168.4.1 — the display shows both.

Getting back into setup later

Press the RESET button twice in quick succession. The display tells you when the window is open. Settings, Wi-Fi and the air-quality calibration can then be reset separately from the setup page.
