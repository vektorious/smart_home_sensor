Smart Home Sensor Web Flasher

Install the firmware onto your board straight from the browser. No Arduino IDE, no drivers.

The European Impact Sprint image has been withdrawn. The sprint is over and its image is no longer installable from this page. Boards already running it are unaffected and keep publishing. Readings last as long as the device keeps sending them: once a device stops, it and its history are removed from the dashboard 48 hours later.

Your board keeps working. Re-flash it with the diy-sensor.org image above, which publishes to the same dashboard.

To keep the same device ID, copy the write key from your setup page before re-flashing, then paste it into the new firmware's Write key field. The sprint image was the only one that could recreate that key, so once the board is re-flashed it is gone: without it the device ID stays claimed by the old key and the dashboard will reject the readings until that device expires.
Your browser doesn’t support Web Serial. Use Chromium, a recent Firefox, Chrome, Edge, or Opera on a desktop computer. Web Serial needs a secure (HTTPS) connection. Open this page over https://.
⚠️ If the board doesn’t show up, start it in flashing mode.
  1. Unplug the board.
  2. Hold the BOOT button down.
  3. Plug in the USB-C cable while still holding BOOT.
  4. Release BOOT after about 2 seconds.
Use a USB-C data cable. A charge-only cable will never enumerate.

How to flash

  1. Pick a firmware above.
  2. Click Connect and choose the USB JTAG/serial debug unit port.
  3. Choose Install and wait for it to finish.
  4. The board reboots and opens a Wi-Fi access point named <device>-Setup. Join it, and the setup page opens at 192.168.4.1. The display shows both.
  5. Name your device, then use Send a test reading to confirm it reaches the dashboard before you walk away from it.

Getting back into setup later

Press the RESET button twice in quick succession. The display tells you when the window is open. Settings, Wi-Fi and the air-quality calibration can then be reset separately from the setup page.
